# 箱建エンジニアリング コーポレートサイト

福島県いわき市の下水道・配管インフラ企業「箱建エンジニアリング」のコーポレートサイトです。
下水道管路更生・管路調査・上下水道／配管工事・維持管理を軸にした、
クリーンで信頼感のあるデザインと、上品なスクロールモーションを備えた静的サイトです。

## 構成

```
.
├── index.html        # ページ本体（1ページ構成）
├── css/style.css     # スタイル（配色・レイアウト・アニメーション）
├── js/main.js        # スクロール演出・ナビ・カウントアップ等
└── assets/favicon.svg
```

## セクション

1. Hero（キャッチコピー＋管路モチーフのアニメーション）
2. About（私たちについて）
3. Service（事業内容：更生／調査／配管工事／維持管理）
4. Strength（強み＋数値カウントアップ）
5. Flow（施工の流れ）
6. Works（施工事例）
7. Company（会社概要）
8. Contact（お問い合わせ）

## 使用技術

- HTML / CSS / バニラ JavaScript（フレームワーク不使用）
- スクロール演出は `IntersectionObserver` で実装
- フォント：Shippori Mincho（見出し）／ Noto Sans JP（本文）／ Manrope（英字）
- `prefers-reduced-motion` に対応（モーション低減設定を尊重）

## ローカルでの確認

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 差し替えが必要な項目（プレースホルダー）

実在の情報に置き換えてご利用ください。

- 会社概要の **所在地・電話番号**（`0246-XX-XXXX`、住所）
- お問い合わせの **電話番号・メールアドレス**（`info@example.com`）
- Strength の **数値実績**（総延長・年数など。※イメージ値）
- Works の **施工写真・事例内容**（現在はサンプルの図形背景）
- 必要に応じて実際の施工写真を `assets/` に追加し、
  `.service-visual` / `.work-thumb` の背景に設定してください。
