# 入札アンテナ いわき：データ収集の試作スクリプト

`mock/index.html` の実データ版を作るのに使った試作スクリプト一式です（2026年9月25日実行）。

## 流れ

1. **公告の収集**：`ppi5.py`（いわき市 入札情報サービスから今年度の建設工事の公告一覧）→ `ppi4.py`（各案件の詳細）→ `ppi7.py`（一般競争の入札公告文PDF）
2. **参加条件の読み取り**：`kk2.py`（公告文PDFから等級・地域要件を抽出）
3. **過去の入札結果**：市HP「建設工事等の入札結果公表」のPDF（スキャン画像）を取得し、`ocr.sh`（ページ全体）と `ocr2.sh`（業者名の列）で Tesseract（jpn）にかける → `parse.py` → `parse3.py`
4. **画面データの生成**：`build_data.py`（箱建の格付けと照合して判定・狙い目度を計算）→ `template.html` に埋め込んで `mock/index.html` を出力

`data/` には生成済みの JSON を入れています。取得元のPDFや画像は容量が大きいため含めていません。

## 注意

- 試作のため、スクリプトは作業ディレクトリ（`raw/`, `png/`, `ocr/` など）を前提にしています。
- OCRの結果には読み取り誤りがあります。箱建に関する行は目で確認済みですが、入札した社数などは概数です。
